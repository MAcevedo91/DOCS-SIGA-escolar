# Centro de Documentación — SIGA Escolar

Bienvenido al repositorio central de documentación de **SIGA Escolar** (Sistema Integral de Gestión y Acompañamiento Escolar).  
Este directorio contiene toda la información técnica, funcional, de diseño, planificación ágil y entregables académicos del proyecto organizada formalmente según la estructura requerida para la defensa de título y entrega institucional.

---

## 🗺️ Estructura del Directorio `DOCS/`

Toda la documentación está centralizada y estructurada dentro del directorio [`Estructura/`](./Estructura/):

```text
DOCS/
├── README.md                                 # Guía de navegación general (este archivo)
└── Estructura/                               # Directorio Maestro con las 11 Secciones Obligatorias
    ├── 01_Resumen_General_del_Proyecto/      # Resumen ejecutivo, alcance, acta de aceptación e informe de avance
    ├── 02_Evidencia_de_Reuniones_con_Stakeholders/ # Minutas, entrevistas, fotos y RICE de la Escuela El Salvador
    ├── 03_Levantamiento_de_Requerimientos/   # Requerimientos IEEE 830, síntesis y propuestas de módulos innovadores
    ├── 04_Carta_Gantt/                       # Cronograma Gantt, control EVM y backlog Jira
    ├── 05_EDT_WBS/                           # Estructura de Desglose de Trabajo jerárquica
    ├── 06_Requerimientos_e_Historias_de_Usuario/ # Requerimientos consolidados, Jira y gestión de Sprints (1 al 11)
    ├── 07_Organizacion_Documental/           # Evidencias de orden y gestión documental
    ├── 08_Evidencia_Tecnica_de_Avance/       # DDL BD, API REST, UAT, diagramas UML (Componentes, Casos de Uso, BPMN)
    ├── 09_Riesgos_y_Problemas_Encontrados/   # Matriz de riesgos, dificultades y planes de mitigación
    ├── 10_Anexos_Obligatorios/               # Manual de usuario, proyecto de título, UI assets y guías de seguridad
    └── 11_Proximos_Pasos/                    # Próximos compromisos, guías de defensa estratégica y pitch de 10 minutos
```
